本模板（继承ctexbook）支持的字体有：
\begin{itemize}
  \item \verb|\songti|{\songti ：设置为宋体，生僻字：垚瑄喆堃赟珺}
  \item \verb|\heiti|{\heiti ：设置为黑体，生僻字：垚瑄喆堃赟珺}
  \item \verb|\kaishu|{\kaishu ：设置为楷体，生僻字：垚瑄喆堃赟珺}
  \item \verb|\fangsong|{\fangsong ：设置为仿宋，生僻字：垚瑄喆堃赟珺}
  \item \verb|\lishu|{\lishu ：设置为隶书，无系统隶书时回退黑体，生僻字：垚瑄喆堃赟珺}
\end{itemize}

以上命令均可与\verb|\bfseries|连用产生合成加粗效果，与\verb|\itshape|连用产生合成倾斜效果。下面是五种字体的常规、加粗与斜体对照：

\begin{itemize}
  \item 宋体常规：{\songti 浙江财经大学软件工程}；加粗：{\songti\bfseries 浙江财经大学软件工程}；斜体：{\songti\itshape 浙江财经大学软件工程}
  \item 黑体常规：{\heiti 浙江财经大学软件工程}；加粗：{\heiti\bfseries 浙江财经大学软件工程}；斜体：{\heiti\itshape 浙江财经大学软件工程}
  \item 楷体常规：{\kaishu 浙江财经大学软件工程}；加粗：{\kaishu\bfseries 浙江财经大学软件工程}；斜体：{\kaishu\itshape 浙江财经大学软件工程}
  \item 仿宋常规：{\fangsong 浙江财经大学软件工程}；加粗：{\fangsong\bfseries 浙江财经大学软件工程}；斜体：{\fangsong\itshape 浙江财经大学软件工程}
  \item 隶书常规：{\lishu 浙江财经大学软件工程}；加粗：{\lishu\bfseries 浙江财经大学软件工程}；斜体：{\lishu\itshape 浙江财经大学软件工程}
\end{itemize}

本模板全文的主环境为宋体，即不带任何字体命令的正文默认就是宋体（\verb|\songti|），这行文字本身即是该环境的样例：正文主环境为宋体垚瑄喆堃赟珺。

上述五个命令都优先使用本机系统字体，探测到系统宋体时正文主字体也一并换成它，因此不带字体命令的正文同样可以显示生僻字。生僻字的支持能力完全取决于字体本身：系统字体、或按 \verb|fonts/README.md| 自备的字体支持生僻字，编译出来的正文就支持；平台连系统字体都没有（如 Overleaf、TexPage）时会落到不含生僻字的 Fandol，此时需要自备字体。

\textcolor{blue}{生僻字：垚瑄喆堃赟珺。}若这行无法看到全部内容，则表示当前字体不支持生僻字，按 \verb|fonts/README.md| 在该目录放置支持生僻字的字体文件即可。

{\kaishu{本模板中使用楷体的环境（如摘要、图表的标题等）用的就是 \verb|\kaishu| 命令，与上面五种字体是同一套解析规则，默认支持生僻字，如：垚瑄喆堃赟珺}}。

有不少同学反映了引号问题。中文引号在中文状态输入即可。英文引号使用\verb|``|（Tab键上方那个键）和\verb|''|（两个单引号，也可以直接使用\verb|"|），如：\verb|``Hello, World!''|，输出为：``Hello, World!''。

行内公式、上下标与数学符号沿用 \LaTeX{} 的写法，如 $E = mc^2$、$a_{i,j}$、$x^{n+1}$、$\alpha \leq \beta \neq \gamma$、$\sum_{k=1}^{n} k$。独立公式用 \verb|equation| 环境编号，引用时用 \verb|\ref|，不要手写编号。

图片用 \verb|figure| 环境插入，图题在图下方，正文中用 \verb|\ref| 引用；表格用 \verb|table| 环境，表题在表上方。图、表、公式的编号与交叉引用由模板统一处理，详见后续章节的示例。
